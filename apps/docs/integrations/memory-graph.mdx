Memory Graph is a React component that visualizes your Supermemory documents and memories as an interactive network. Documents appear as rectangular nodes, memories as hexagonal nodes, and connections between them show relationships and similarity.

<Card title="@supermemory/memory-graph on npm" icon="/icons/hugeicons/package.svg" href="https://www.npmjs.com/package/@supermemory/memory-graph">
    Check out the NPM page for more details
</Card>

## Installation

```bash
npm install @supermemory/memory-graph
```

**Requirements:** React 18.0.0 or higher

## Quick start

Fetch one page of the graph from your backend (see [Backend API route](#backend-api-route)) and convert it with `graphPageToDocuments`:

```tsx
'use client'; // For Next.js App Router

import { MemoryGraph, graphPageToDocuments } from '@supermemory/memory-graph';
import type { GraphApiDocument, GraphPage } from '@supermemory/memory-graph';
import { useEffect, useState } from 'react';

export default function MemoryGraphPage() {
  const [documents, setDocuments] = useState<GraphApiDocument[]>([]);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    fetch('/api/graph')
      .then(res => {
        if (!res.ok) throw new Error(`Graph request failed: ${res.status}`);
        return res.json() as Promise<GraphPage>;
      })
      .then(page => setDocuments(graphPageToDocuments(page)))
      .catch(setError)
      .finally(() => setIsLoading(false));
  }, []);

  return (
    <div style={{ height: '100vh' }}>
      <MemoryGraph
        documents={documents}
        isLoading={isLoading}
        error={error}
        variant="console"
      />
    </div>
  );
}
```

## Optional rendering and document navigation

Existing icon-based document nodes and connection styling remain the defaults. Opt in to stacked squares and stronger semantic connections with `appearance`:

```tsx
<MemoryGraph
  documents={documents}
  appearance={{ documentNodes: 'stacked', connections: 'emphasized' }}
  openDocumentOnEnter
  onOpenDocument={openPersistedDocument}
/>
```

`documentNodes` accepts `'icons'` or `'stacked'`; `connections` accepts `'default'` or `'emphasized'`. Both fields are optional and also work on `GraphCanvas`. Stacks stay inside existing node bounds and simplify at low zoom. Use `colors.edgeDocument` to configure document-source ink; older custom `GraphCanvas` palettes without that field use `textSecondary` in emphasized mode.

`openDocumentOnEnter` is off by default. With an `onOpenDocument` callback, `MemoryGraph` exposes a focused Enter action for the selected persisted document or one confirmed memory source. Typing, modifier shortcuts, repeats, composition and keys outside the graph do not open documents. Your callback retains responsibility for routing and access control; consumers without a callback receive no new opening behavior.

## Backend API route

Create a server route that reads the graph for the signed-in user's namespace. `POST /ns/{namespace}/graph` returns up to `limit` documents (at most 100) with their memories as `{ nodes, edges, nextCursor }`. Pass `nextCursor` back as `cursor` for the next page; it is `null` on the last page. Return the page as is and convert it in the browser with `graphPageToDocuments`.

<CodeGroup>

```typescript Next.js App Router
// app/api/graph/route.ts
import { NextResponse } from 'next/server';

export async function GET(request: Request) {
  const namespace = 'user_123'; // the signed-in user's namespace
  const params = new URLSearchParams({ limit: '100' });
  const cursor = new URL(request.url).searchParams.get('cursor');
  if (cursor) params.set('cursor', cursor);

  const response = await fetch(
    `https://api.supermemory.ai/ns/${encodeURIComponent(namespace)}/graph?${params}`,
    {
      method: 'POST',
      headers: { Authorization: `Bearer ${process.env.SUPERMEMORY_API_KEY}` },
    },
  );

  return NextResponse.json(await response.json(), { status: response.status });
}
```

```typescript Next.js Pages Router
// pages/api/graph.ts
import type { NextApiRequest, NextApiResponse } from 'next';

  const namespace = 'user_123'; // the signed-in user's namespace

    },
  );

  res.status(response.status).json(await response.json());
}
```

## Examples

### With pagination

Load the next page on `onLoadMore` while `nextCursor` is set, appending each page's documents:

```tsx
'use client';

import { MemoryGraph, graphPageToDocuments } from '@supermemory/memory-graph';
import type { GraphApiDocument, GraphPage } from '@supermemory/memory-graph';
import { useCallback, useEffect, useState } from 'react';

export default function PaginatedGraph() {
  const [documents, setDocuments] = useState<GraphApiDocument[]>([]);
  const [cursor, setCursor] = useState<string | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [isLoadingMore, setIsLoadingMore] = useState(false);
  const [error, setError] = useState<Error | null>(null);

  const fetchPage = useCallback(async (after: string | null) => {
    const res = await fetch(after ? `/api/graph?cursor=${encodeURIComponent(after)}` : '/api/graph');
    if (!res.ok) throw new Error(`Graph request failed: ${res.status}`);
    const page: GraphPage = await res.json();
    const next = graphPageToDocuments(page);
    setDocuments(prev => (after ? [...prev, ...next] : next));
    setCursor(page.nextCursor);
  }, []);

  useEffect(() => {
    fetchPage(null)
      .catch(setError)
      .finally(() => setIsLoading(false));
  }, [fetchPage]);

  const loadMore = useCallback(async () => {
    if (!cursor || isLoadingMore) return;
    setIsLoadingMore(true);
    try {
      await fetchPage(cursor);
    } catch (err) {
      setError(err as Error);
    } finally {
      setIsLoadingMore(false);
    }
  }, [cursor, isLoadingMore, fetchPage]);

  return (
    <MemoryGraph
      documents={documents}
      isLoading={isLoading}
      isLoadingMore={isLoadingMore}
      error={error}
      hasMore={cursor !== null}
      onLoadMore={loadMore}
    />
  );
}
```

## Props reference

### Core props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `documents` | `GraphApiDocument[]` | `[]` | Array of documents to display |
| `isLoading` | `boolean` | `false` | Shows loading indicator |
| `error` | `Error \| null` | `null` | Error to display |
| `variant` | `"console" \| "consumer"` | `"console"` | Visual variant |
| `children` | `ReactNode` | - | Custom empty state content |

### Pagination props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isLoadingMore` | `boolean` | `false` | Shows indicator when loading more |
| `hasMore` | `boolean` | `false` | Whether more documents available |
| `onLoadMore` | `() => void` | - | Called to load more, for example when the user zooms out past the loaded nodes |
| `totalCount` | `number` | - | Total document count shown by the loading indicator |

### Display props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `highlightDocumentIds` | `string[]` | `[]` | Document IDs to highlight |
| `highlightsVisible` | `boolean` | `true` | Whether highlights shown |
| `maxNodes` | `number` | - | Maximum number of nodes to display |
| `colors` | `Partial<GraphThemeColors>` | - | Theme color overrides |
| `labels` | `MemoryGraphLabels` | - | User-facing label overrides |
| `appearance` | `GraphAppearance` | - | Opt-in document node and connection styles (see above) |
| `openDocumentOnEnter` | `boolean` | `false` | Enable the Enter action that calls `onOpenDocument` |
| `onOpenDocument` | `(documentId: string) => void` | - | Called when the user opens a document |

## Performance

The graph handles hundreds of nodes efficiently through:
- Canvas-based rendering (not DOM elements)
- Viewport culling (only draws visible nodes)
- Level-of-detail optimization (simplifies when zoomed out)
- Change-based rendering (only redraws when state changes)

For very large datasets (1000+ documents), use pagination to load data in chunks.

## Browser support

Works in all modern browsers supporting Canvas 2D API, ES2020, and CSS custom properties. Tested on Chrome, Firefox, Safari, and Edge.
