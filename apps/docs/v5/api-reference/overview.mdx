V5 makes namespace scope explicit in the URL and consolidates overlapping legacy operations.

```text
https://api.supermemory.ai
  /ns/{namespace}/document
  /ns/{namespace}/search
  /ns/{namespace}/profile
  /ns/{namespace}/list/{type}
  /ns/{namespace}/memories
  /namespaces
  /organization
```

Use `/v5/reference` for the stable V5 reference. `/reference` always points to the latest public version.
