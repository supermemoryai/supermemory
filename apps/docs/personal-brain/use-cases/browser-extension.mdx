Save webpages and conversations from Chrome without leaving the tab.

## How the Supermemory Chrome extension works

The Supermemory Chrome Extension saves webpages, imports bookmarks, and adds ChatGPT and Claude conversations to your Personal Brain.

## Before you start

- A Supermemory account with Personal Brain access
- Signed in at [app.supermemory.ai](https://app.supermemory.ai)
- Google Chrome
- The active organization and Space you want to save into

## How to install and connect the Chrome extension

<Steps>
  <Step title="Open Integrations in Personal Brain">
    Go to Integrations and select Browser extension.
  </Step>
  <Step title="Install the Chrome Extension">
    Add the extension from the Chrome Web Store.
  </Step>
  <Step title="Sign in through the extension">
    Sign in to Supermemory from the extension so it saves into your account.
  </Step>
  <Step title="Choose the correct Space">
    Select the Space that matches the context you're saving into before you save anything.
  </Step>
  <Step title="Save a page to confirm">
    Open a page and use the extension to save it. Check that it appears in the chosen Space.
  </Step>
</Steps>

## How the extension talks to Supermemory

The extension talks to Supermemory from Chrome. It saves the current page, imports bookmarks in bulk, or adds the current ChatGPT or Claude conversation to your selected Space.

## What the browser extension saves and imports

- Save: the current webpage and, optionally, a selection or note
- Import: existing Chrome bookmarks
- Add to Supermemory: the current ChatGPT or Claude conversation

## How to save a ChatGPT conversation to Supermemory

Open the ChatGPT conversation you want to save, then select the Supermemory icon in the Chrome toolbar. The extension shows the current conversation and the Space it will be saved to.

<Steps>
  <Step title="Open the ChatGPT conversation">
    Go to the conversation you want to add to your Personal Brain.
  </Step>
  <Step title="Open the Supermemory extension">
    Select the Supermemory icon in the Chrome toolbar.
  </Step>
  <Step title="Choose a Space">
    Confirm where you want the conversation to be saved.
  </Step>
  <Step title="Add the conversation">
    Select **Add to supermemory**.
  </Step>
</Steps>

{/* Add screenshot of the Supermemory extension open on the "Create SEO YouTube metadata" ChatGPT conversation. */}

The conversation is added to the selected Space and becomes available alongside the rest of your saved memory.

## How to save a Claude conversation to Supermemory

Open the Claude conversation you want to save, then use the same browser extension flow. You do not need to ask Claude to remember or save anything.

<Steps>
  <Step title="Open the Claude conversation">
    Go to the conversation you want to add to your Personal Brain.
  </Step>
  <Step title="Open the Supermemory extension">
    Select the Supermemory icon in the Chrome toolbar.
  </Step>
  <Step title="Choose a Space">
    Confirm where you want the conversation to be saved.
  </Step>
  <Step title="Add the conversation">
    Select **Add to supermemory**.
  </Step>
</Steps>

{/* Add screenshot of the Supermemory extension open on the "User analytics table" Claude conversation. */}

The conversation is added to the selected Space. ChatGPT and Claude conversations can live in the same Personal Brain, so your saved context is not limited to one assistant.

## Limitations of the browser extension

- Chrome is the supported browser. Other browsers are not covered here.
- Saves land in the active Space chosen in the extension. Confirm the Space before saving.
- Bookmark import brings existing bookmarks in once. It is not the same as a live sync.

## How to troubleshoot the Chrome extension

- **A saved page did not appear.** Check the active organization, active Space in the extension, and that the memory finished processing.
- **Sign in loops.** Sign in to Supermemory at [app.supermemory.ai](https://app.supermemory.ai) first, then reopen the extension.
- **Add to supermemory did not work.** Confirm you're signed in to Supermemory, the conversation is open in the same Chrome profile as the extension, and the correct Space is selected.
