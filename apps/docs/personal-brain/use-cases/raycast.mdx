## How the Supermemory Raycast extension works

Adds memories from Raycast on Mac and searches Supermemory directly from the desktop command bar.

## Before you start

- A Supermemory account with Personal Brain access
- Signed in at [app.supermemory.ai](https://app.supermemory.ai)
- Raycast installed on macOS
- The active organization and Space you want to use

## How to install and connect the Raycast extension

<Steps>
  <Step title="Open Integrations in Personal Brain">
    Go to Integrations and select Raycast.
  </Step>
  <Step title="Install the Raycast extension">
    Install the Supermemory extension from the Raycast store.
  </Step>
  <Step title="Connect your account">
    Sign in from the extension so Raycast can save and search in your Supermemory account.
  </Step>
  <Step title="Choose the correct Space">
    Select the Space you want the commands to use.
  </Step>
  <Step title="Try Add memory and Search memory">
    Run the add and search commands from Raycast to confirm the connection.
  </Step>
</Steps>

## How Raycast talks to Supermemory

Raycast talks to Supermemory through the extension. Add memory sends the input to your active Space. Search memory queries the same Space and shows matches inline.

## What Raycast saves and searches

- Save: text, links, or selections passed to the add command
- Search: your memory in the Space Raycast is pointed at

## Limitations of the Raycast extension

- Raycast runs on macOS. Other launchers are not covered here.
- Commands run against the active Space chosen in the extension. Confirm it before saving or searching.
- Some commands rely on macOS accessibility and clipboard permissions granted to Raycast.

## How to troubleshoot Raycast

- **Commands don't run.** Confirm you're signed in from the extension and the connection status is active.
- **A saved memory did not appear.** Check the active organization and Space, and that processing finished.
- **Search returns nothing.** Confirm the Space matches the one you saved into.
