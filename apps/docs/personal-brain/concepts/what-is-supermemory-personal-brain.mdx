Personal Brain gives you one memory across the apps and AI tools you use. Save something once, then search it in Supermemory or recall it from a connected tool when you need it.

<CardGroup cols={2}>
  <Card title="Save" icon="bookmark">
    Add notes, links, files, webpages, and content from connected apps.
  </Card>

  <Card title="Recall" icon="search">
    Search your memory, ask questions, or bring relevant context into another AI tool.
  </Card>
</CardGroup>

Ask questions and Nova pulls the right context from your memory.

<Frame>
  ![Nova chat with memory map](/images/personal-brain/nova-chat.png)
</Frame>

## A quick example

<Steps>
  <Step title="Save a project decision.">
    Capture the decision in Supermemory so it's part of your memory.
  </Step>
  <Step title="Open a new chat in a supported AI tool.">
    Start fresh without pasting background or context.
  </Step>
  <Step title="Recall the decision without explaining it again.">
    Your memory is available in the tool, so the decision comes back on demand.
  </Step>
</Steps>

## Where you can use it

- Supermemory app
- Browser extension
- Poke
- Apple Shortcuts
- Raycast
- MCP clients and coding plugins

Personal Brain integrations, MCP clients, coding plugins, and data connectors all connect to the same memory but have different setup flows.
